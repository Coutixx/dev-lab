# Dev Lab

Laboratório pessoal de estudos e experimentação em desenvolvimento de software.

O objetivo deste repositório é estudar fundamentos, testar conceitos na prática e registrar descobertas. A ideia é entender **como as coisas funcionam**, e não apenas aprender a utilizá-las através de abstrações.

## Ordem de estudos

A sequência inicial será:

1. **Terminal**
2. **Git**
3. **SQL**
4. **HTTP**
5. **Docker**
6. **.NET**
7. **CI/CD**

A ordem pode ser alterada conforme a necessidade e a evolução dos estudos.

---

## 1. Terminal

Base para trabalhar com sistemas e ferramentas de desenvolvimento.

Principais assuntos:

* Navegação no sistema de arquivos
* Arquivos e diretórios
* Permissões
* Processos
* Variáveis de ambiente
* `stdin`, `stdout` e `stderr`
* Pipes
* Redirecionamento
* Shell scripting

---

## 2. Git

Controle de versão e colaboração com código.

Principais assuntos:

* Repositórios
* Commits
* Branches
* Merge
* Rebase
* Conflitos
* Histórico
* Remotes
* GitHub

---

## 3. SQL

Fundamentos de bancos de dados relacionais.

Principais assuntos:

* DDL

* Constraints
* CRUD

* WHERE

* GROUP BY
* Agregações
* Índices

## 4. HTTP

Principais assuntos:

* Request

* Status Codes
* Body

* APIs REST

---

## 5. Docker

Entender isolamento, empacotamento e execução de aplicações.

Principais assuntos:

* Images
* Containers

* Volumes
* Networks
* Docker Compose

---

## 6. .NET

Principais assuntos:

## 7. CI/CD

Principais assuntos:

---

## Filosofia do laboratório

Cada assunto deve ser estudado principalmente através de experimentação.

Para cada conceito, buscar responder:

* **O que é?**
* **Como funciona?**
* **Como utilizar?**
* **O que acontece quando algo dá errado?**

Sempre que possível, os estudos devem possuir exemplos executáveis.

O objetivo não é criar uma coleção de tutoriais, mas construir **entendimento prático e capacidade de resolver problemas**.
